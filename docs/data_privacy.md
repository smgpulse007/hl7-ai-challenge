# Data Privacy

This repository is intended for public portfolio and challenge review.

It uses synthetic, generated, or sample data only and does not include:

- protected health information
- personally identifiable information
- real member, patient, provider, payer, or employer records
- production credentials
- proprietary claims logic or confidential clinical workflows

Any real healthcare deployment would need formal HIPAA/security review, data governance, audit logging, access controls, model validation, and clinical workflow approval.
